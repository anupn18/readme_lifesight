Klaviyo is an intelligent marketing automation platform specializing in email and SMS marketing for e-commerce brands. It focuses on helping direct-to-consumer (D2C) businesses own their customer relationships and drive revenue by delivering highly personalized communication. Its core purpose is to increase customer lifetime value and encourage repeat purchases.

### Setup Guide

1. Log in to your Klaviyo account.
2. Go to the Account section in the Klaviyo dashboard.
3. Navigate to Settings and select API Keys.
4. Click on the Create API Key button.
5. Select Write Scopes for the Events, Metrics, Lists and Profiles Objects and create API key.
6. Copy the generated API key.
7. Paste the API key in the Lifesight Klaviyo Integration pop up box.

<br />

## Access Scopes Required for the API Key:

1. **Events and Metrics Read Access:** Required to fetch metrics such as email opens, email clicks, and SMS clicks from Klaviyo.
2. **Events Write Access:** Required to send Lifesight events to Klaviyo.
3. **Profiles and Lists Write Access:** Required to sync Lifesight segments as lists on Klaviyo.
