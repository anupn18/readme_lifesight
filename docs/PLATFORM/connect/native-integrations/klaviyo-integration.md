## Overview

Klaviyo is a powerful email and SMS marketing platform designed to help businesses grow through personalized communications. By leveraging data-driven insights, Klaviyo enables businesses to send targeted messages to their audience, increasing engagement and driving sales. This integration between Lifesight and Klaviyo aims to enhance marketing outcomes by enabling more precise audience targeting, personalized messaging, and comprehensive performance tracking. The key features of this integration include:

1. **Custom Audience Sync:**\
   Lifesight segments can be seamlessly pushed to Klaviyo, creating custom audiences for email and SMS campaigns. This capability ensures that businesses can deliver highly relevant and personalized content to their audience, improving engagement rates and conversion outcomes.
2. **Data Integration:**\
   This integration facilitates the smooth transfer of audience data, including demographics, purchase behavior, and interaction history, into Klaviyo. This data is vital for creating targeted campaigns and understanding the nuances of audience behavior, ultimately leading to more effective marketing strategies.
3. **Performance Insights:**\
   Marketers can access detailed performance metrics of their Klaviyo campaigns within the Lifesight dashboard. This feature provides actionable insights, helping to refine audience segments, optimize content, and allocate resources more effectively to maximize return on investment.

<br />

## Use Cases

**Enhance Email and SMS Campaigns**\
By syncing audience segments from Lifesight to Klaviyo, businesses can craft highly personalized email and SMS campaigns that resonate with their target audience. This leads to higher open rates, click-through rates, and conversions, driving overall business growth.

**Improve Targeting Precision**\
Utilize the rich demographic and behavioral data from Lifesight to create more precise audience segments in Klaviyo. This precision enables businesses to send the right message to the right people at the right time, enhancing the effectiveness of marketing efforts.

**Maximize Marketing ROI\*\***\
Through detailed performance insights available in Lifesight, businesses can continuously optimize their Klaviyo campaigns. By understanding what works and what doesn’t, marketers can make informed decisions that improve campaign efficiency and increase the return on investment.

## Steps to integrate Klaviyo with Lifesight:

1. Log in to your Klaviyo account.
2. Go to the Account section in the Klaviyo dashboard.
3. Navigate to Settings and select API Keys.
4. Click on the Create API Key button.
5. Select Write Scopes for the Events, Metrics, Lists and Profiles Objects and create API key.
6. Copy the generated API key.
7. Paste the API key in the Lifesight Klaviyo Integration pop up box.

<br />

## Access Scopes Required for the API Key:

1. **Events and Metrics Read Access:** Required to fetch metrics such as email opens, email clicks, and SMS clicks from Klaviyo.
2. **Events Write Access:** Required to send Lifesight events to Klaviyo.
3. **Profiles and Lists Write Access:** Required to sync Lifesight segments as lists on Klaviyo.
