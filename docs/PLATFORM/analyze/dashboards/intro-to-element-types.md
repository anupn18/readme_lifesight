Dashboards typically contain a collection of elements on a single page and/or distributed across multiple pages.

There are three element types: data elements, UI elements, and control elements. Each has a unique function, and they collectively allow you to display, interact with, and provide additional context to your data.

Dashboard editors define elements and can individually configure them for viewer interaction.

## Data Elements

Data elements include tables, pivot tables, and visualizations built directly from a data source. A Dashboard can contain a variety of data elements derived from multiple data sources.

## UI Elements

UI elements include buttons, dividers, images, spacers, embeds, and text used to add context and/or Dashboard styling.

<Image align="center" src="https://files.readme.io/ef69b8539147c0da2d24d87681657c782aa55c6feabea0e382dfd15664181366-4a6bb19-2.png" />

## Control Elements

Control elements include data filters and parameters used to manipulate data elements in the Dashboard.
