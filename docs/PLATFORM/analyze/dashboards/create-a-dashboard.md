Dashboards are a Lifesight document type designed to support both ad hoc data exploration and complex long-term reporting. The collaborative interface and visual approach to data interaction make live data accessible to everyone in your organization.

Unsaved Dashboards are referred to as explorations and are available on the Recents page for 30 days.

This document shows how to create a new Dashboard

## Requirement

To create new Dashboards and explorations, you must be assigned the Creator, Admin, or custom account type with the appropriate permissions

## Create a Dashboard or Exploration

### ... from the navigation panel

To create a Dashboard or exploration from the navigation panel:

1. In the left navigation panel, click + Create New.
2. Select Dashboard from the dropdown menu. Lifesight creates and redirects you to a blank new Dashboard.
3. Explore your data in the Dashboard. You can add data elements, calculations, controls, etc.
4. In the Dashboard header, click Save As to save your exploration as a Dashboard for later use.

### ... from a data source

To create a Dashboard or exploration from a data source (warehouse table or Lifesight dataset):

1. Open the data source.
2. In the Dashboard header, click Explore. Lifesight creates and redirects you to a new Dashboard with a default table element connected to the data source.
3. Explore your data using the Dashboard interface. You can add data elements, calculations, controls, and more.
4. In the Dashboard header, click Save As to save your exploration as a Dashboard for later use.

### ... from a template

A Dashboard template is a Lifesight document type that allows you to use, reuse, and share specific Dashboard structures for quick and consistent exploration and reporting.

### ... from an existing Dashboard

To create a copy of an existing Dashboard:

- Click the caret button to the right of the Dashboard title in the header.
- Select Save as.  
  Lifesight opens the Save a Copy modal.
- (Optional) Enter a new Name.
- (Optional) Select a Destination.
- Click Save.
