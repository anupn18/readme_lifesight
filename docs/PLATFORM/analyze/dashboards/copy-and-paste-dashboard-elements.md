Lifesight's copy-and-paste functionality allows you to replicate elements in various locations. You can copy and paste an element within its originating Dashboard, or you can copy an element from one Dashboard and paste it in another.

## User requirements

The ability to copy and paste elements requires the following:

- You must be assigned an account type with the Explore Dashboards or Create, edit, and publish Dashboards permission enabled.
- You must be the Dashboard owner or be granted Can explore or Can edit Dashboard permission.

## Copy and paste an element

Copy an element, then paste it in an empty space or directly below an existing element in the destination Dashboard. If you copy a child element, its lineage is also copied and pasted.

### Copy the element

1. Open a Dashboard in any mode, then select or hover over the element you want to copy.
2. In the element toolbar, click  More to open the element menu, then select Copy element. The original element and all applicable parent elements in its lineage are copied.

### Paste the element in an empty space

1. Open the destination Dashboard in Explore or Edit mode, then find an empty space in the canvas.
2. Right-click the empty space to open the action menu, then select Paste element.

### Paste the element below an existing element

1. Open the destination Dashboard in Explore or Edit mode, then select or hover over an existing element.
2. In the element toolbar, click  More to open the element menu, then select Paste element below.
