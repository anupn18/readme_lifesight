When you edit a Dashboard, you create a draft. To make the changes visible to Viewers, you publish the draft. You can also choose to discard your draft, and return to the previously published version.

Any user with Can Edit access to the Dashboard can edit it. You enter Edit mode by clicking the Edit button.

If multiple users edit a Dashboard at the same time, the edits are automatically saved to a shared, live draft. Multiple editors can collaborate on this single draft in real-time.

When a user views or explores a saved Dashboard, they see the most recent published version.

This document describes how to edit drafts and publish Dashboards and how to delete and restore deleted Dashboards.

## Requirement

To draft and publish new Dashboard versions, you must have Can Edit access to the individual Dashboard.

## Edit an existing Dashboard

To begin editing an existing Dashboard, click Edit in the Dashboard header.

After the Dashboard enters Edit mode:

- The Edit button changes to an Editing menu.
- The version menu changes from PUBLISHED to DRAFT.
- The header displays a list of all users currently in Edit mode.
- Click a user’s icon to navigate to the element they have selected (if they have one selected).
- Dashboard elements show the name of the user or users who are currently selecting the element.
- The editor panel and sidebar appear on the left side of the page.
- Changes you make to the draft automatically save to the live draft shared by all editors.
- If an editor clicks Publish, Lifesight publishes all drafted changes, including changes drafted by all editors on the live draft.

## Preview drafted changes

You can preview all drafted changes in both Explore and View modes prior to publishing. This is helpful if you want to see what a Dashboard will look like to users with View or Explore permissions to access to the Dashboard.

To preview drafted changes:

1. Click Editing.
2. Select either Preview as explorer or Preview as viewer.
3. To change states again, click Previewing and select your target state.

## Publish drafted changes

To publish your edits, click the Publish button located in the Dashboard header.

This action publishes all drafted changes to the Dashboard, including changes made by other editors using the live draft.

## Discard drafted changes

To discard your drafted changes, click Editing > Restore the draft to the published version.

Lifesight discards all users' unpublished edits, not just yours.

## Return to the latest published version

To return to a Dashboard's latest published version, click Editing > Go to published version. Lifesight places the Dashboard into Explore mode.

Lifesight does not discard your drafted changes. You can return to the shared draft at any time by clicking the published version's Edit button.

## Delete a dashboard

To delete a Dashboard you must be the owner of the Dashboard, have Can edit access to it, or have the Admin account type.

1. Click on the drop-down next to the Dashboard name, then click Delete....
2. On the Confirm Deletion modal, click Delete.

## Recover a deleted dashboard

1. To recover a Dashboard that has been deleted, you must be the owner of the Dashboard or have the Admin account type.
2. Go to your Home page.
3. In the navigation menu, select Trash.
4. In the Trash page, search the list of deleted documents and click the one you want to recover. You can sort the Name, Deleted on, or Deleted by columns to help identify the applicable document.
5. In the Document has been deleted modal, click Recover. Lifesight immediately opens the recovered document.
