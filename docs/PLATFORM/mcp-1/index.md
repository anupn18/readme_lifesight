Lifesight MCP brings your unified causal measurement model directly into ChatGPT, Claude, and other MCP-compatible AI tools.

Instead of switching between dashboards, reports, and analysts, teams can ask questions in natural language and get answers grounded in Lifesight's measurement engine.

Open your AI assistant, ask a business question, and get a clear answer backed by causal methodology, measurement logic, and recommended actions.

**What is MCP? **

Model Context Protocol (MCP) is an open standard that allows AI applications to securely access external data sources and tools. The Lifesight MCP server provides AI agents with:

* Direct API access to Lifesight functionality 
* Documentation search capabilities
* Real-time data from your Lifesight account 
* Code generation assistance for Lifesight integrations
