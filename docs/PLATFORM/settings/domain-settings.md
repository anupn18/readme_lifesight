* To enhance data privacy, comply with regulations, and improve data collection accuracy, we recommend proxying our JavaScript SDK script. This step ensures the script is not blocked by ad blockers and privacy extensions, allowing you to gather more precise data by leveraging first-party data advantages.
* Setting up this domain proxy will ensure that data collection appears as first-party data, originating from the website's domain instead of Lifesight's domain. This approach is intended to enhance data privacy, comply with regulations, and improve data collection accuracy by leveraging first-party data advantages.

The provided A record under ***Domain*** must be added in the website's DNS Settings. 

Below are resources for adding A records on popular domain providers:

[Managing A records on GoDaddy](https://www.godaddy.com/en-in/help/add-an-a-record-19238)

[Managing A records on Google Domains](https://support.google.com/a/answer/2579934?hl=en)

[Managing A records on Namecheap](https://www.namecheap.com/support/knowledgebase/article.aspx/319/2237/how-can-i-set-up-an-a-address-record-for-my-domain/)

[Managing A records on Hostinger](https://support.hostinger.com/en/articles/4468886-how-to-manage-a-records)
