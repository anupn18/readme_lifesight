The Triangulation feature enables users to set custom attribution weights for different ad channels, allowing more precise control over attribution metrics such as **Platform Reported Clicks (PRC)** and **Lifesight Tracked Clicks (LTC)**. 

By default, the system uses calculated weights for each channel (e.g., Facebook, Google, TikTok), but users can override these with custom weights or revert to defaults as needed.

![](https://files.readme.io/1812c2fd7aa09bb8d17dc37116697dcba7242d48d4ec37b7dd8b1a9c66bde58d-image.png)

## Anchor Attribution Methodology

- Platform conversions, 
- Lifesight UTM conversions.

<br />

## How to set custom attribution weights?

1. Navigate to Settings > Triangulation tab
2. Select your preferred anchor attribution method (Coming soon)
3. Enter custom weights in the for each channel in the table to apply them on your anchor attribution methodology.
