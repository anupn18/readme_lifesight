The Experiments dashboard gives you an overview of all the experiments run on Lifesight.

<Image align="center" src="https://files.readme.io/63a00611a5296596490f302db4df162dff01b0361534800937b73a8d1ca43dfa-Experiments_home_screen.png" />

## Key Components

1. **Name** - The name of the Experiment you set while creating an experiment
2. **Outcome/KPI** - Mentions the outcome KPI the experiment was run for (could be Revenue, Conversions, Store Lift, etc)
3. **Platform** - Mentions the platforms on which the experiment was run.
4. **Status** - Indicates the current stage of the experiment.
5. **Test Date** - Shows the planned or executed period for the experiment
