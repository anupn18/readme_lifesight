The Default Scenario powers the Recommendations section and Goals feature in the Lifesight platform. 

## How to set a default scenario

1. Navigate to Action > Planner.
2. [Build a plan](https://docs.lifesight.io/docs/build-a-media-plan) using the Planner.
3. Once you have simulated and tested multiple scenarios, a user select a default scenario by clicking on the "Star" icon. 

<Image align="center" src="https://files.readme.io/4731c5357abf9472b70d240091a2174a4d84eca7dcd4066d87f38989d9ec6c9e-def.jpg" />

<br />

> 🚧 You can select multiple default scenarios in a workspace.
>
> * You can select only 1 default scenario for each KPI you choose. 
> * Each default scenario will have separate Recommendations and Goals for each KPI you choose to optimize for.

<br />

## Default Scenarios are indicated with a "Star" icon next to the plan for easy identification.

![](https://files.readme.io/b2710a54d76e11d41cb71bb92a0ca1276f5d1ad2938ae4bbf7fbb1053a070268-image.png)

> ❗️ Plans which have default scenario can only archived and not be deleted from the Plan's overview table.
>
> You have to select another model as default to be able to delete the plan.
