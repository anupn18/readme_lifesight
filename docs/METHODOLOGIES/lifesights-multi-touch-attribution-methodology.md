Attribution relies on being able to build a very accurate and holistic user journey across all the "trackable" touchpoints. This user journey can then used to build detailed conversion report to understand the association between various sources (channels, tactics, campaigns, creatives , ...) and conversion events (page visit, sign up, checkout initiation, checkout completion, ...) 

<br />

Heuristic Based Conversion reports, Modelled Attribution report and also to Infer "unobserved" interactions in some cases.

Lifesight builds a detailed and persistent first-party graph that is independent of cookies and other browser limitations.

The purpose of this attribution is to compare the platform reported revenue and the incremental revenue associated with the platform.

The formula to calculate this is by using multiplying: (iROAS for campaign spends or if that isn't present then iROAS for campaign spend)\*platform reported ROAS (pROAS)

With this information you can find out how much incremental effect of marketing spend at Platforms, Campaign, Ad groups and Ads.
