# Creating a Plan

The Lifesight 4.0 scenario wizard creates the first scenario and its underlying plan in three steps.

[IMAGE PLACEHOLDER: New Scenario wizard]

## Step 1: Basics

Select the promoted model outcome used for planning. Then choose an objective:

- **Optimize Budget** to find a more effective allocation for the planned budget
- **Hit Revenue Goal** to work toward a specified business outcome

Enter a short, unique scenario name. If you entered Planner from a model, the model can be preselected and locked.

[IMAGE PLACEHOLDER: Basics step with model, objective, and scenario name]

## Step 2: Time Period

Set the plan period and reference period. The plan period is the future or current window being optimized. The reference period provides the baseline allocation and outcome used for comparison.

Use the same period last year when it represents current seasonality and market behavior. Use a recent period when the business has materially changed.

[IMAGE PLACEHOLDER: Time Period step with planning and reference windows]

## Step 3: Constraints

Review current budget, enter planned budget, and select an optimization strategy. Configure channel minimum and maximum bounds and update non-media drivers when required.

For revenue goals, review the efficiency threshold and target settings available for the selected model.

[IMAGE PLACEHOLDER: Constraints step with channel bounds]

## Run the scenario

Select **Run simulations**. Planner creates the plan and processes the scenario. Results appear when the simulation completes.

[VIDEO PLACEHOLDER: Creating and running a new plan]

## Save the plan

Select **Save Plan** after all scenarios in the plan have completed. Draft plans that have not been explicitly saved do not appear in Plan List.
