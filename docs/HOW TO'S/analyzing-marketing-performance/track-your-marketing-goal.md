Lifesight allows you to monitor the progress of your marketing goals effectively by providing real-time analytics and insights. This guide will help you understand how to track your marketing goal progress using Lifesight.

## Steps to Track Your Marketing Goal Progress

1. [Create](https://docs.lifesight.io/docs/model-creation) and run a MMM model.
2. Once you're confident in your model performance, navigate to the `Action > Planner` feature.
3. Create a plan using the following [steps](https://docs.lifesight.io/docs/how-to-build-a-plan).
4. Mark a plan as a [default scenario](https://docs.lifesight.io/docs/default-scenario)
5. Once you're done, navigate to `Analyze > Goals`
6. You should be able to track your outcome KPI (Revenue, Leads, etc).

<br />

> 📘 You can track multiple marketing goals at the same time.
>
> * The Goal KPI should be selected while creating a MMM model. The outcome KPI must be mapped and uploaded during model creation to track the desired KPI as a goal.
> * If you select more than 1 default scenario for the same goal KPI, Lifesight automatically selects the plan that has less aggressive contraints to track in the Goals tab.
