# Build a Media Plan

Build a media plan in Lifesight 4.0 by creating a scenario, running the simulation, and saving the resulting plan.

[IMAGE PLACEHOLDER: New Plan and New Scenario controls in Planner]

## Create the first scenario

1. Go to **Forecast > Planner**.
2. Select **New Plan** or **New Scenario**.
3. In **Basics**, select the promoted outcome model, choose an objective, and name the scenario.
4. In **Time Period**, set the planning period and reference period.
5. In **Constraints**, enter the planned budget, select a constraint preset, review channel bounds, and configure non-media drivers.
6. Select **Run simulations**.

[VIDEO PLACEHOLDER: Completing the three-step scenario wizard]

## Review and refine

After the simulation completes, review:

- Total budget and forecasted outcome
- Incremental outcome and iROAS or iCPA
- Recommended channel allocation
- Forecast trend and confidence interval
- Monthly forecast table
- Budget worksheet
- Saturation curves
- Pacing and dimension breakdowns

Change configuration in the left panel and select **Run Simulation** again to update the results.

## Compare scenarios

Select **New Scenario** to add another scenario to the active plan. A new scenario must use the same model as the other scenarios in the plan. Copying the active scenario is useful when testing a controlled change in budget, period, or constraints.

[IMAGE PLACEHOLDER: Multiple scenario tabs in a plan]

## Save, export, and promote

Run every scenario before saving. Select **Save Plan**, enter a plan name, and confirm. Use **Export** to download the available worksheet output.

Promote the selected scenario when it should become the active input for Decisions and Deploy.
