# Breakdown

The **Breakdown** tab provides a detailed causal attribution view across the marketing hierarchy.

[IMAGE PLACEHOLDER: Attribution Breakdown tab]

## Select a level

Available levels appear when data exists for them:

- Channels
- Tactics
- Campaigns
- Ad Sets

Select one or more rows, then choose **Drill into** to filter the next level using your selection. Clear the selection when you want to return to the full level.

[VIDEO PLACEHOLDER: Drilling from a channel into tactics and campaigns]

## Search and organize the table

Use search to find an entity by name or account. Select **Choose columns** to show, hide, and reorder metrics. Columns with no data or only zero values can be hidden automatically to keep the table focused.

Common columns include recommendation, pacing, actual and planned spend, spend delta, impressions, clicks, platform revenue, incremental revenue, platform ROAS, iROAS, marginal ROAS, conversions, incrementality factor, and CPA.

## Review recommendations

Recommendations compare actual spend with the active scenario:

- **Scale** for entities that are under plan
- **Maintain** for entities pacing near plan
- **Reduce** for entities that are over plan

## Open the weekly view

Select **Weekly** for an entity to inspect planned and actual spend by week, pacing, weekly and cumulative delta, daily averages, and the recommended daily spend for the next seven days.
