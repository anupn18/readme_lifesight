# Getting Started with Attribution

Attribution in Lifesight 4.0 requires connected advertising data and promoted measurement inputs that support causal results.

[IMAGE PLACEHOLDER: Attribution workspace empty and populated states]

## 1. Connect marketing platforms

Go to **Integrations** and connect the advertising platforms used by your workspace. Confirm that each connection is active and receiving current campaign data.

## 2. Prepare measurement inputs

Create and validate the Marketing Mix Models and experiments used for incremental measurement. Promote the assets that should contribute to Attribution and model calibration.

## 3. Configure a scenario

Prepare the planning scenario that provides planned spend and the benchmark used by causal recommendations. The Attribution Overview compares actual activity with this active scenario.

## 4. Open Attribution

Go to **Measure > Attribution** and select a date range. Review the last updated indicator before interpreting the results.

[VIDEO PLACEHOLDER: Opening Attribution and reviewing the active scenario]

## 5. Review Overview and Breakdown

Use **Overview** for headline spend, incremental revenue, iROAS, pacing, and channel performance. Use **Breakdown** to inspect channel, tactic, campaign, and ad set results.

## Best practices

- Keep platform integrations active and current
- Use comparable date ranges when reviewing changes
- Review platform-reported and incremental metrics together
- Confirm the active scenario before acting on pacing recommendations
- Validate important changes with MMM and experiment evidence

If the workspace shows no attribution data, confirm that the data pipeline, promoted measurement assets, and permissions are configured.
