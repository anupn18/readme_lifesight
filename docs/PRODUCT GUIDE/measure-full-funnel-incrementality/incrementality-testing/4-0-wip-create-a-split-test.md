# Split Test Creation

The legacy Split Test creation flow is not available in Lifesight 4.0. New experiments are currently created with the Geo Testing workflow.

[IMAGE PLACEHOLDER: New Experiment page with Geo Testing available]

## Create an available experiment

1. Go to **Measure > Experiments**.
2. Select **New Experiment**.
3. Choose **Geo Testing**.
4. Complete the Goal, Data, and Design steps.
5. Submit the design to find recommended markets.

Time Testing and external experiment import are visible as coming soon and cannot currently be selected.

## If you need audience randomization

Do not translate a user-level Split Test directly into a geo design without reviewing the measurement objective. Audience randomization and geographic market assignment have different data, contamination, power, and operational requirements.

[VIDEO PLACEHOLDER: Available and coming-soon experiment types]

Contact your Lifesight representative to confirm the appropriate workflow for an audience-level test or to discuss availability.
