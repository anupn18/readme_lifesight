# Geo Test Insights

Use **Monitoring & Results** to evaluate a running or completed Geo Test in Lifesight 4.0.

[IMAGE PLACEHOLDER: Completed Geo Test results]

## Calculate lift

For a running experiment, select **Calculate Lift** when an interim analysis is required and upload updated geo data. At the end of the treatment period, upload final treatment-period data to calculate the final result.

The upload should extend the same schema and granularity used during experiment creation.

[VIDEO PLACEHOLDER: Uploading updated geo data and calculating lift]

## Review statistical evidence

Evaluate:

- Current or final lift
- Adjusted lift when available
- iROAS and adjusted iROAS
- P-value
- Statistical power
- Confidence interval
- Whether the interval excludes zero

## Compare treatment and control

The treatment-versus-control chart compares observed test-market performance with the counterfactual trend. Review fit before treatment and divergence during treatment.

Use the market breakdown to understand how individual test and control areas contributed to the result.

[IMAGE PLACEHOLDER: Treatment-versus-control chart and market breakdown]

## Use the result

Review findings and the experiment conclusion with the original hypothesis. Promote a credible completed result when it should support Attribution or eligible MMM calibration workflows.

> Interim results are provisional and can change as more data is added. Avoid ending a test solely because an early result appears positive or negative.
