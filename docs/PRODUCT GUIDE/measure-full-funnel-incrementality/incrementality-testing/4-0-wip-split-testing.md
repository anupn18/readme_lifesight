# Split Test

Audience Split Testing is not available in the Lifesight 4.0 experiment creation workflow.

[IMAGE PLACEHOLDER: Lifesight 4.0 experiment design selection]

The current workflow supports **Geo Testing**. **Time Testing** and importing external experiments are shown as coming soon. The legacy Split Test workflow, which divided an audience into treatment and control groups, is not exposed in 4.0.

## Use Geo Testing when appropriate

Geo Testing separates markets rather than individual audience members. It can be used to evaluate channel incrementality, scale-up strategies, spend levels, tactics, creative strategies, audiences, promotions, and MMM recommendations.

## Geo Testing workflow

1. Define a hypothesis and treatment.
2. Upload historical geo-level KPI data.
3. Configure the experiment design.
4. Select recommended test and control markets.
5. Schedule campaigns.
6. Calculate and review lift.

[VIDEO PLACEHOLDER: Selecting Geo Testing and reviewing the creation flow]

> Do not use Geo Testing as a direct substitute when the business question requires randomized user-level assignment. Confirm the appropriate design with your Lifesight representative.
