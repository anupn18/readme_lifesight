# Geo Test Creation

Create a Geo Test from the Experiments workspace in Lifesight 4.0.

[IMAGE PLACEHOLDER: New Experiment button in the Experiment List]

## Create the test

1. Go to **Measure > Experiments**.
2. Select **New Experiment**.
3. Choose **Geo Testing**.
4. In **Goal**, name the experiment, select or write a hypothesis, and choose Hold-out or Scale-up.
5. In **Data**, upload a CSV and configure the KPI, date, geo, pre-treatment period, and column mappings.
6. In **Design**, configure cells, channels, tactics, target iROAS, durations, and test-market counts.
7. Select **Find markets**.

[VIDEO PLACEHOLDER: Creating a Geo Test in the three-step wizard]

## Review recommended markets

When market selection completes, review recommended test markets, synthetic-control fit, power analysis, minimum detectable lift, and investment estimates. Select the market combination that fits the business and statistical requirements.

## Select campaigns and schedule

Choose eligible campaigns for each cell. For Hold-out, select activity to exclude in test markets. For Scale-up, identify the control campaigns your team will duplicate for test markets.

Select a start date and deployment method, then promote and schedule the experiment when all cells are ready.

[IMAGE PLACEHOLDER: Selected markets and campaign scheduling]

> Confirm platform setup and operational ownership before the start date. Manual deployment requires your team to apply the planned changes in the advertising platform.
