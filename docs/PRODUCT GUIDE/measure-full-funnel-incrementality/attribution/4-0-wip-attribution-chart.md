# Attribution Chart

Lifesight 4.0 presents attribution trends through focused cards and tables instead of a standalone configurable attribution chart.

[IMAGE PLACEHOLDER: Attribution Overview visualizations]

## Revenue comparison

The **Overview** tab compares platform-reported revenue with incremental revenue. This view helps identify how much reported revenue is estimated to be causally driven by advertising.

The incrementality factor is calculated as:

`Incremental Revenue / Platform-Reported Revenue`

## Pacing against plan

Use the pacing view to compare actual spend with planned spend for the active scenario. It shows:

- Scenario progress and days remaining
- Overall pacing percentage
- Cumulative spend versus plan
- Channels that are on track, behind plan, or ahead of plan
- Daily adjustments suggested for under-pacing and over-pacing channels

[IMAGE PLACEHOLDER: Pacing against plan card]

## Weekly trends

In the **Breakdown** tab, select **Weekly** for an entity to review planned spend, actual spend, pacing, weekly delta, cumulative delta, daily averages, and the recommended daily spend for the next seven days.

[VIDEO PLACEHOLDER: Opening the weekly breakdown for a channel]

## Change the analysis

Use the date picker to change the reporting range. Use the target scenario control to change the benchmark or scenario that drives planned spend and recommendations.
