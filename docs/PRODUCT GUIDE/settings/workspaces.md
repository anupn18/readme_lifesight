## Add/Delete a workspace

Users with the permission of "Admin" can create multiple workspaces within an account as per the signed Lifesight contract. 

> 📘 This feature is available to Agencies to add Brands/Clients into a workspace.

1. Click your workspace name on the top right and select `Settings` from the dropdown menu.

<Image align="center" src="https://files.readme.io/5fe467e9dd5df92d1146ac4d91a2fec1fe0cf92e201491fc7332929149e70c22-readme_pics_1.jpg" />

2. Switch to the "Workspace" tab

![](https://files.readme.io/4ef3495c9c58707938340440c0636e3ca196a647ebc7154fc8e64c0ce266598e-image.png)

3. Select `Add Workspace` button to add a new workspace.

![](https://files.readme.io/72dd8c92b6435bb134b4dd611380211f6284d2de4adedfd4bf10d658a43f346c-image.png)

4. You can view your newly created workspace in the list.

![](https://files.readme.io/7dd1bf17c883a35f267ae113a30f947ff13986f5723b97afeb7fb813b4bdef61-image.png)
