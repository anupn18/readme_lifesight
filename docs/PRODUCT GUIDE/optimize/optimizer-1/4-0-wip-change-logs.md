# Logger

The **Logs** view in Lifesight 4.0 records actions sent from Deploy to connected advertising platforms.

[IMAGE PLACEHOLDER: Deploy Platform Logs view]

## Access the logs

1. Open **Deploy**.
2. Select **Logs** in the page header.
3. Open **Platform Logs**.

[VIDEO PLACEHOLDER: Opening and filtering Deploy logs]

## Review log details

Log entries can identify the platform, user, action type, scope, affected entity, previous value, new value, status, and time of the change. Related changes can be grouped for easier review.

Common action types include:

- Budget Update
- Bid Update
- Status Update
- Creative Update
- Target Update
- Geo Targeting Update
- Campaign Created

## Search and filter

Use the available controls to filter by user, channel, action, scope, and time period. Search logs when you need to locate a specific campaign, entity, or change group.

[IMAGE PLACEHOLDER: Log filters and expanded change group]

## Troubleshoot an action

If a deployment action does not produce the expected result, review its status and details in Logs. Confirm platform permissions and entity eligibility, then retry only after understanding the prior response.

> Logs provide an audit trail of Deploy actions. They do not replace the advertising platform's own change history.
