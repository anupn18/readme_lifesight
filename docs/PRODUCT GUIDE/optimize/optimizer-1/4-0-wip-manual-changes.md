# Manual Changes

Deploy in Lifesight 4.0 lets authorized users apply recommended values or enter custom changes for eligible advertising entities.

[IMAGE PLACEHOLDER: Campaign actions in Deploy]

## Change a budget

1. Open **Deploy** and select **Campaigns** or **Ad Sets**.
2. Open an entity action or enable **Select multiple**.
3. Select **Change Budget**.
4. Choose **Custom**.
5. Enter the new budget for each eligible entity.
6. Review warnings and excluded entities.
7. Select **Apply Budget Change**.

[VIDEO PLACEHOLDER: Applying custom campaign budgets]

## Change a bid value

Select **Change Bid Value**, choose the supported mode, and enter a new bid target. Review the current strategy, recommendation availability, and scenario-duration cautions before applying.

## Change campaign status

Select **Change Status** and set each eligible campaign to Active or Paused. For multiple entities, use the set-all control when the same status should apply to every row.

[IMAGE PLACEHOLDER: Bulk status change dialog]

## Eligibility and permissions

Supported actions vary by platform, entity, and connected-account permissions. Deploy excludes entities that do not support the selected field and shows them before confirmation.

## Track changes

After applying a change, open **Logs** to confirm its status and review the previous and new values.

> Custom changes can differ from the promoted plan. Record the business reason and review the effect on pacing and future recommendations.
