These Quickstart Guides are designed to get your team from setup to decision in hours (with tests running over weeks). Follow them in order for the fastest time‑to‑value, or jump to the guide that matches your immediate need.

Recommended order

Connect your data → establish the minimum viable dataset

Run your first “Measure” read → baseline incrementality & marginal effects

Launch a geo‑lift test → causal proof for debated channels/tactics

Calibrate attribution with incrementality → align daily KPIs to causal truth

Build a forecast & plan → pick a scenario and export a pacing worksheet

The guides

1. Quickstart: Connect your data

Fast path using top connectors or CSV templates; verification checks.
Slug: /start/quickstart-connect
Get your core commerce, analytics, and media data into Lifesight via native connectors or CSV templates, then run light parity and mapping checks so your first Measure read is trustworthy.
You’ll get: connected sources or CSVs mapped, last 7–14 days verified, workspace timezone/currency set, and a refresh schedule.

2. Quickstart: Run your first “Measure” read

Baseline incrementality and marginal effects; interpret outputs; next actions.
Slug: /start/quickstart-measure
Generate a causally grounded baseline showing incremental vs. baseline contribution and marginal returns by channel/tactic. Turn curves into a short scale / cap / test move list.
You’ll get: a saved readout, channel/tactic contribution, marginal curves with saturation flags, and a prioritized action list.

3. Quickstart: Launch a geo‑lift test

Test vs control, power, timing; read‑out expectations; common pitfalls.
Slug: /start/quickstart-geo-test
Design a reliable geo test (holdout or scale‑up) with matched markets, ≥80% power, pacing guardrails, and a clear decision rule. Monitor cleanly and deliver a decision‑grade read‑out.
You’ll get: an approved test plan, live monitoring checklist, and a read‑out that quantifies incremental lift and informs calibration.

4. Quickstart: Calibrate attribution with incrementality

Apply lift factors; align daily KPIs to causal truth.
Slug: /start/quickstart-calibrate-attribution
Translate evidence from geo tests and Measure into incrementality‑adjusted KPIs so day‑to‑day optimization reflects causal impact—not platform bias.
You’ll get: a documented calibration map, adjusted conversions/ROAS/CAC at channel/tactic (and later campaign) level, dashboard updates, and guardrails.

5. Quickstart: Build a forecast & plan

Scenario setup, constraints, and exporting a pacing worksheet.
Slug: /start/quickstart-forecast-plan
Create Efficiency, Balanced, and Growth scenarios using the latest curves and lift evidence. Add constraints and guardrails, compare outcomes under uncertainty, choose a plan, and export pacing.
You’ll get: 2–3 forecasted scenarios, one approved plan with uncertainty bands, a pacing worksheet (channel × week), and guardrails for execution.

After you complete the quickstarts

A single, causal truth shared by marketing and finance

A running learning agenda with geo tests feeding calibration

Incrementality‑adjusted KPIs guiding daily optimization

A profit‑aligned plan with pacing and enforceable guardrails
