Deploy shows one recommendation per entity: Scale, Reduce or Maintain, with an amount. This page covers where those recommendations come from, what governs them, and who can apply them.

## Where recommendations come from

Recommendations are generated by Causal Attribution against your promoted plan. The plan sets the target allocation, your promoted incrementality source sets what each entity is actually returning, and the recommendation is the gap between the two. Nothing is derived from platform reported performance alone.

Two conditions must hold before any recommendation exists:

* A calibrated incrementality source, either a promoted model or an adopted geo experiment.
* A promoted plan covering the period.

With a plan but no calibration, there is nothing to recommend against. With calibration but no plan, there is no target to pace toward.

## What gets a recommendation

Recommendations are produced only for entities that can act on them. An entity qualifies when it holds its own budget, is active, is inside its delivery window, and has recent delivery. Entities that fail any of these do not appear.

Budget ownership decides the level. A campaign using campaign budget optimisation holds the budget, so the recommendation sits on the campaign. Under ad set budget optimisation each ad set holds its own, so the recommendations sit on the ad sets. An entity appears at one level only, the level where the change can be made.

Recommendations also respect platform rules. A bid target can only be set where the campaign's bidding strategy supports one, so entities on automated bidding carry no target.

## Reading a row

* Recommendation: Scale, Reduce or Maintain, with the amount.
* Current Budget: what is set on the platform today, with its type, daily or lifetime, and whether budget is held at campaign or ad set level.
* Spend: recent delivery, the context for judging the size of a move.
* Bid Strategy and Bid Target: the current bidding setup.
* Deploy Status: whether the recommendation has been actioned.

Campaigns sharing a budget appear as separate rows, but an edit applies once at the shared budget level.

## Acting on a recommendation

Only workspace Managers and Admins can edit or apply.

Take the recommended figure, or switch to Custom and enter your own. Apply to a single row from its menu, or select several rows and apply the same action to all of them at once. A confirmation step shows current against new values before anything is sent.

Applied changes are pushed to the ad platform and recorded in Logs, with what changed, who changed it, and when.
