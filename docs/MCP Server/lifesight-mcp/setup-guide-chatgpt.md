**Before you start:** you need an active Lifesight workspace.

## Connect Lifesight in ChatGPT

1. In ChatGPT, open **Plugins**, select **Lifesight**, then select **Connect**.
2. Sign in to Lifesight and choose a workspace you belong to.
3. Review the requested permissions and continue. When you return to ChatGPT, ask **"Which Lifesight workspace am I currently in?"** Confirm the workspace before running a report or planning a budget.

For more prompts to try, see the [MCP Prompt Library](https://docs.lifesight.io/docs/mcp-prompt-library).

## Understand your permissions

Each permission is granted separately for each workspace.

| Permission | What you can do                                                                                                                                                   |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Read**   | View workspace measurement data and run what-if analyses. A what-if can create a temporary scenario or store a chart preview in Lifesight.                        |
| **Write**  | Save named budget plans. The workspace's default plan stays as it is.                                                                                             |
| **Decide** | Request a change to the workspace default plan. A person in your workspace approves or rejects the request in Lifesight. The default changes only after approval. |

Standard access includes Read. A workspace admin can enable Write and Decide.

## Get help connecting

If you can't connect, ask your workspace admin to check **Workspace Settings → Claude & MCP → Which apps may connect → ChatGPT**. For other issues, contact [support@lifesight.io](mailto:support@lifesight.io).

## Disconnect and manage your data

To disconnect ChatGPT, go to **Settings → Claude & MCP → Your connected clients** in Lifesight. For data requests, contact [privacy@lifesight.io](mailto:privacy@lifesight.io). To learn how Lifesight handles your data, read our [Privacy Policy](https://lifesight.io/privacy-policy/).
